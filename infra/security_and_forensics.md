# 全城节律监测网、跨频刑侦与反侦察实战

> 在新历城，人体心跳与呼吸速率本身就是最难伪造的身份证。治安天眼网络全天候追踪全城十余亿个脉搏频率，而地下黑市与亡命逃犯则围绕这些物理信号展开了一场又一场毫秒与百年尺度的攻防暗战。

## 一、新历城「微多普勒天眼与能耗稽查网」

除传统的高清光学人脸、虹膜与步态识别外，新历城在 `Layer -2 ~ +4` 的主要立交枢纽、磁浮轨交闸机、高墙关口以及核心商圈灯柱上，密集部署了两套针对时间分化人群的专有监测基建：

### 1.1 太赫兹微多普勒节律雷达
* **核心原理**：可在 `10 ~ 25` 米非接触距离内隔着衣物、普通木板乃至轻型货车箱体，捕捉内部活体的心脏微弱搏动与胸腔起伏频率。
* **常态异常识别规则**：
  * 行走于街面的 `n=0` 与 `n=-1/3` 活跃人群均呈现 **`60 ~ 100` 次/分** 的标准现世心跳与持续呼吸；
  * 当一辆密闭物流货车或民居地下室内部探测出 **每 `6` 分钟仅微弱搏动一次（`n=365`）** 或 **几十秒乃至几分钟一次（`n=29 / n=60`）** 的超低频信号，同时该空间未在配额局注册任何合法金库资质或居家医疗特批照护备案（如林昼为妹妹林夏申请的居家恒温看护备案）时，天眼主脑会在 `3` 秒内直接拉响 **「违规私藏沉睡活体 / 无证黑舱走私警报」**。

### 1.2 市政电网分路波动特征稽查
* 常规住宅电力负荷会随 `n=0` 晚间熄灯、`n=1/2` 相位交班出现明确的阶梯波动；而供养一个非法 `T2/T1` 级别私密休眠舱，必须连续几个月乃至数年在地下维持高精度 **`17.5℃ ± 0.2℃` 恒温微制冷/防潮环流**——这种**毫无波动的直线微弱恒温基荷曲线**，正是林昼等金库审计员携带分路电表钳下井抓黑舱、甚至当年在皇宫外围审计中意外撞破亚层能耗死锁的铁证（详见 [energy_vaults_and_logistics.md](./energy_vaults_and_logistics.md#L18-L24)）。

## 二、跨频刑事侦查学：警探如何靠“时间差”破案？

新历城警署刑侦总队内部按频段搭配联合作业——由全天候死磕现场的 `n=-1/3` 突击警探、精通太阳历常规物证的 `n=0` 法医痕检官，以及负责梳理数十年跨代陈年连环旧案的 `n=6` 高级顾问共同协作：

### 2.1 通过现场痕检锁定嫌疑人 `n` 值
当凶案现场未拍到清晰面容时，痕检组通常依靠四项细节反推出嫌犯的生物参数：
1. **残渣胃容与冷热餐盒周期**：嫌犯逃匿途经安全屋的垃圾桶内，外卖包装密封时间、残羹冷却温度与代谢排泄频率能迅速区分出“每天三顿高卡流食的永昼人”还是“刚醒来第一小时进食的错峰族”。
2. **「`17~19` 小时微睡眠步态」取证**：调取周边街区连续 `48` 小时监控，若某一蒙面人物在某连续几小时内频繁出现突然刹停、扶墙眨眼 `2~3` 秒、方向感短暂失焦甚至无端擦撞路灯的微睡眠症状，即可反向精确推算出其**本轮苏醒起始时刻（`00:00`）**。
3. **全麻馆耗氧与麻醉清零记录**：若某无名账户每隔几天便在固定区域购买两小时纯全麻体验且氧耗偏高，几乎可直接锁死为精神高压的资深 `n=-1/3`（或正用全麻强行消磨清醒窗口的在逃人员）。
4. **熬夜相位碰撞反查**：调取城内所有三叶草公寓物业报修记录与水电违约门锁日志，任何一次清晨突然出现的“`96:00` 门厅冲突”或“单人连续未离室长达一周”，都会暴露嫌疑人的动态睡债状态。

### 2.2 抓捕实战中的「睡潮窗口狙击法」
* **围猎 `n=-1/3` 亡命徒（「磨钟战术」）**：针对火力凶猛且警惕性极高的永昼暴徒，警方由精力饱满的 `n=0` 轮班特勤组实施多梯次交替封锁与高频佯攻，硬生生将目标拖入连续高强度逃亡超过 **`30` 小时以上**——待对方大脑积聚海量突触噪点爆发幻听与手部震颤后再从容突入擒获。
* **围堵高 `n` 叛逃者（例如追捕 `217` 号）**：面对一旦睡下便无法自行逃脱、但醒后拥有极高权限与冷静思维的高 `n` 目标，追捕行动彻底转化为一道**精准日历加法题**——专案组依据目标最后一次强撑目击时刻（如 `217` 号在 `16:30` 逃出皇宫，`Δ = 0.5h`）乘以 `1:548` 偏移系数，精确算出目标将顺延至 **第 `377` 天** 方才睁眼（同时派出探员在第 `366` 天与第 `377` 天双重时段提前两小时封死所有备选安全屋电源与电梯井道）。
* **审讯 `15.5` 小时红线管控**：依据《新历法典》第 `203` 条（见 [legal_code_and_statutes.md](./legal_code_and_statutes.md#L77-L80)），嫌疑人在自身清醒超过 `15.5` 小时后签署的供词均可依法申请无效。审讯室大门上方同步倒数嫌犯腕表与生物电疲劳度，探员集中全力在目标清醒第 `1 ~ 14` 小时内完成审讯突破并即时归档录音录像。

## 三、地下藏匿与反侦察实战守则（屏蔽物流箱运作细则）

对于林昼、唐夜以及黑市走私团伙而言，在 `549` 共同体与警网的联合清剿下护送一名昏睡的高 `n` 逃犯（如箱内的 `217` 号）横穿都市，全赖三套苛刻的反侦察工艺：

1. **三层复合材料伪装物流箱**：外层包覆高频铅箔隔热屏蔽层与阻尼悬架，内藏模拟正常工业精密试剂恒温箱的外部电源接口与伪造电子物流运单；箱底嵌入微弱振动与伪多普勒**「生物假频发声器」**——对外散发出 `n=0` 实验仓鼠或常规医疗冷链泵的伪装震动波纹，遮蔽内部每 `6` 分钟一次的深层沉睡脉搏。
2. **「`72` 小时切线游击法」掩护热尾迹**：严密控制单一电网节点的挂载时长，在同一变电站支路挂载严格限定在 `72` 小时以内，随后立即切换至城市下一处热工排风口或废旧地铁阴影夹层；优先借道 `Layer 0` 早晚工业冷却水排放高峰转移箱体，将冷机散热尾迹完美混入厂房万千吨工业废热之中，避开审计钳表的直线恒温曲线追踪。
3. **「苏醒预热盲区」转移窗口**：黑医通过屏蔽箱外部独立控制芯片手动压低唤醒前两小时的预热启动信号（或精准踩中目标因第一幕熬夜而触发的真实日历推迟时刻），彻底错开敌方按旧日历时间表设下的 `366` 天定点伏击圈，完成绝地反击的最后潜伏期。
