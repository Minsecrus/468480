# 跨频婚恋、家庭伦理与代际错位

> 在清醒总额人人平等而日历寿命相差数倍甚至数百倍的社会里，婚姻不仅是两个灵魂的结合，更是两套不同时间速率的资产与生命托付。一纸跨频婚书往往意味着一方白发垂暮时，另一方尚在人生的第一个清晨。

## 一、择偶市场的「同频闭环」与婚前寿限尽调

### 1.1 相亲鄙视链与同频内婚铁律
由于跨频伴侣面临极难调和的日历衰老差与生活节律错位，新历城婚恋市场高度呈现**「同频闭环」**：
* **婚前强制尽调清单**：男女双方正式登记前，惯例通过市政联网交换两项核心底单——**民政核磁神经 `n` 值法定回执**（杜绝畸零人冒充 `n=0` 骗婚）与 **家族/个人托管偿付能力证明**（详见 [economic_tax_and_contracts.md](./economic_tax_and_contracts.md#L33-L41)）。
* **各频段婚姻市场生态**：
  * **`n=0` 基准人**：婚恋体量最大、最看重双方同频育儿与稳定双薪按揭；对求偶列表中标出 `n=-1/3` 的相亲对象普遍敬而远之（担忧对方四五十岁后因记忆过载引发家暴倾向或早逝留下一屁股债）。
  * **`n=-1/3` 永昼人**：高度集中在工区内部或同为科研高压从业者之间缔结「战友式短程婚姻」，双方都能承受高强度连轴作息与极短的晚年陪护期待。
  * **`n=1 / n=2` 错峰族**：相亲与婚配优先寻找**完全同 `n`** 的对象（只要周期长度相同，即便初始相位相差半个周期，婚前或同居前只需一起请几天「合表假」主动向右多熬几小时即可零药物永久对齐；真正挑剔初始现成相位的，主要是尚无力独立整租、仍被各自单位或合租排班表锁死的单身打工人）。已合表的伴侣常在三叶草公寓附近合租专用的「双卧格联通家庭房」（两口子对齐同一清醒窗口，另有一名外租 `n=2` 室友错峰占用客厅）。
  * **高 `n` 财阀（`n ≥ 29`）**：婚姻本质上是不同长眠家族信托之间的股份并购，通常只限周期整除回归年（`n=60, 182, 365`）的同阶层门第之间联姻。

### 1.2 跨频婚约的高危联保条款
一旦发生跨频结合（如 `n=0` 嫁给 `n=2`，或 `n=-1/3` 娶了 `n=0`），《新历民法典》要求婚姻登记处加签**《跨频寿命差与休眠期联保告知书》**：
* **长眠期共同财产冻结权**：若高 `n` 一方处于连续数周乃至数年的深睡期间，低 `n` 配偶仅能动用婚前划定的「现世日常生活额度」，无权擅自变卖、抵押高 `n` 配偶名下资产与金库权益。
* **生理年龄差预设**：签署时即明确确认双方衰老速度比。以 `n=0`（寿命 `80` 岁）与 `n=2`（寿命 `204` 岁）为例，当 `n=0` 配偶步入 `75` 岁衰老垂危之际，`n=2` 配偶才刚刚走过约三分之一成年清醒期，容貌尚相当于普通人的三十余岁。

## 二、亲密成本：当“为你熬过第 `16` 小时”变成奢侈品

* **「15:30 拔线矛盾」**：恋爱初期，高 `n` 一方咬牙硬撑陪低 `n` 恋人熬夜聊天、互道“为你多睡九小时也值”是最具杀伤力的浪漫情话。步入婚姻柴米油盐后，每当家庭争吵正激烈、或亲人突发情绪崩溃，一旦腕表响起 `15:30` 提示音，错峰与高 `n` 一方基于生存本能瞬间冷静摘表、饮热牛奶退入暗室休眠，常令留在客厅独自面对一地鸡毛的 `n=0` 或 `n=-1/3` 伴侣感到透骨冰寒与情感被弃感。
* **同 `n` 锁死 vs 跨 `n` 异频的「同步窗口奢侈税」**：对于同为 `n=1 / n=2` 却尚未攒够钱退掉错峰合租床位的穷情侣，尽管只需一次几天的滑相就能彻底对齐，昂贵的整租差价与企业转岗罚金仍逼得他们一年才敢破戒拥抱一回；而对真正**周期长度互质的跨 `n` 异频伴侣**而言（例如 `n=1` 配 `n=2` 虽每 `144` 小时即 **`6` 天**必定存在一次自然交集，却因模 `24h` 相位偏移常常只斜擦 `4~6` 小时——为了在重合日凑出完整的 `16` 小时双人旅行，低 `n` 一方会提前一两轮微调晚睡去迎合对方睁眼窗口；至于 `n=29`（`30` 天）配 `n=365`（`366` 天）这类最大公约数为 `6` 天、最小公倍周期长达 **`5` 年（`1,830` 天）** 的极少数跨代深爱者，若模 `6` 天的余数原本差开一两天则更是千年永不碰面，非得由 `n=29` 伴侣算准天数特意多熬 `1~3` 小时硬把余数跳进同一日历轨、才能换来五年一度的短暂清晨相聚）。

## 三、休眠期婚姻法理、延时告别与代际反向伦理

### 3.1 配偶长眠期间的法律难题
* **休眠期「分段婚姻」与忠贞豁免**：针对 `n ≥ 29` 的富豪或病患阶层，法律允许缔结**「有限唤醒伴侣契约」**——`n=365` 贵族在沉睡的一整年里豁免对现世 `n=0` 配偶的陪护义务；而极少数与常醒者结婚的极高 `n` 居民（如两年至十年一醒的 `n ≥ 731` 者）一旦连续沉睡数年未醒，现世方在履行足额护理/信托照管义务后，若长期处于事实单身状态且经相位家事法庭核准，可依法申请解除婚姻关系或按婚前协议进入「单方生活期」。
* **唤醒后的延迟丧偶告知**：若 `n=0` 伴侣在高 `n` 配偶长达一年的深睡中途突然意外身故，金库守夜人与家事官会直接封存遗物、办理火化葬礼，直至下一次目标自然预热睁眼时，才由「苏醒简报官」在 `00:02`（前五分钟生死线通报段）以平静语调宣布半年前已完成的丧礼与继承公证结果。

### 3.2 「延时告别录像馆」与跨越半世纪的遗书
新历城各地民政厅与高端殡仪馆普遍经营一项特色业务——**「跨频时空封存留言馆」**：
* 临终的 `n=-1/3` 父亲或病危的 `n=0` 妻子，在自己人生最后的清醒窗口里走进全息录音棚，录下微笑叮嘱与对伴侣、儿女的告别；
* 这些全息包按接收人的 `n` 值日历严格加密封存：**若接收方是 `n=29`（月醒）或 `n=365`（年醒）亲属**，往往要在录制者逝世一个月至一年后的某个清晨才能解锁送达（或是生前预先替幼子、妹妹录好未来十年乃至几十年的“每年元旦/生日定期分批解封信”，如林昼提前为妹妹林夏存下的多年祝词）；**而若接收方是 `n=3,659`（十年一醒）或 `n=18,299`（五十年一醒）等数十年长眠的远房高 `n` 祖辈**，更是直到录制者早已化作骨灰 **十几年甚至半个世纪后**，全息影像才会在其刚满 `00:05` 的清晨桌面上自动弹出播放——**生者对着早已消失在历史尘埃里的年轻面孔流泪，却连一朵鲜花都来不及赶在热乎时送上**。

### 3.3 代际反向伦理：「反向养老」与「白发儿女坟头」
传统“养儿防老”在时间分化社会里出现双向崩坏：
1. **永昼父母的早逝悲剧**：`n=-1/3` 父母熬到 `55~59` 岁生命尽头时，其遵循正常 `n=0` 节律成长的儿女往往刚刚 `30` 出头，正值成家立业压力峰值却已不得不独自面对双亲衰老、神经紊乱乃至送终火化。
2. **高 `n` 父母的“儿女墓园基金”**：反过来，对于 `n=6`、`n=29`、`n=365` 乃至十年一醒的极高 `n` 家族，当家长才刚刚活到生理中年（看起来像三四十岁壮年）时，当初那批选了 `n=0` 或 `n=-1/3` 的儿女、甚至孙辈已纷纷步入垂暮或先后入土。长眠财阀族谱里于是专门设有一笔**「低频后裔暮年养老与墓园维护基金」**——容颜未改的青年家长按周、按月、按年乃至每隔十年醒来一次，面无表情地签批自己八十岁逝世儿子的骨灰格续费账单。
