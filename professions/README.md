所有行业推演均严格遵守 [main.md](../main.md) 的底层公式：
* 全人类终身清醒总额严格守恒于 **`468,480` 小时**（`18` 岁后剩余 **`363,072` 小时**）；
* 生物周期为 $24(n+1)$ 小时（醒 $16$ 小时 + 睡 $24n+8$ 小时），回归年严格等于 **`366` 天（`8,784` 小时）**；
* 主动打破睡潮触发双向对称调相，额外睡眠/缩减睡眠按 **`1 : (1.5n + 0.5)`** 结算，总日历偏移按 **`1.5(n + 1)Δ`** 计算。
